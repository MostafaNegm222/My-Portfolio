# My Portfolio

## 1. Description

A portfolio website built from scratch with HTML, CSS and JavaScript, with a contact form and project showcases linking to live demos.

## 2. Technologies and Versions

- HTML5, CSS3, vanilla JavaScript (no build step)
- EmailJS Browser SDK 4 (contact form, via CDN)
- LineIcons 4.0 (icons, via CDN)
- ScrollReveal 4.0.0 (scroll animations, via CDN)

## 3. Requirements and Dependencies

- A modern web browser
- No packages to install; an internet connection is needed for the CDN libraries

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/My-Portfolio.git
cd My-Portfolio
```

Open `index.html` in a browser, or serve the folder with any static server.

## 5. Environment Variables

None required. (The EmailJS keys live in the JavaScript for the contact form.)

## 6. Usage and Main Features

- Single-page portfolio: `index.html` with styles under `css/`, scripts under `js/`, assets under `image/`.
- Contact form sending through EmailJS.
- Scroll-in animations with ScrollReveal.
- Links to live demos of other projects.
